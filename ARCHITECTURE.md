# Architecture

The detailed SemantIQ architecture specification is maintained in
[Docs/ARCHITECTURE.md](Docs/ARCHITECTURE.md).

SemantIQ's current software identity is **`0.1.0-alpha.2` — Public Alpha
(Experimental)**. Architecture descriptions should be read together with the
[Known Limitations](Docs/KNOWN_LIMITATIONS.md) and the
[Integration Graph](Docs/ecosystem/INTEGRATION_GRAPH.md).

The presence of a package, service, adapter, historical subsystem, or design
document in the repository does not by itself make that component part of the
current supported public product boundary. The source/package boundary is being
reconciled separately and must be established from implementation and dependency
evidence rather than from legacy phase labels.
