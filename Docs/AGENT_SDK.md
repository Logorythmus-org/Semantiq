# Agent SDK

The Agent SDK lets developers create custom agents.

## Agent Manifest

Capabilities, goals, permissions, memory requirements, tools, events, benchmark rules, learning policies, health checks, and cost estimates.

## Runtime Boundary

Agents communicate through Agent OS and do not bypass workspace, wallet, workflow, marketplace, or compute permissions.

## Benchmarking

Custom agents define benchmark rules so Semantiq can evaluate reliability, quality, safety, and value.
