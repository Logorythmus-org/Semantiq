# AI Agent Roles

Question Intelligence uses specialized agents.

## Agents

- Question Refiner Agent: improves clarity while preserving meaning.
- Intent Agent: detects one or more intents.
- Ambiguity Agent: finds unclear terms, scope, context, time, domain, audience, goal, evidence, and definitions.
- Assumption Agent: classifies hidden assumptions.
- Evidence Agent: suggests evidence types and search strategies without fabricating sources.
- Relation Agent: proposes semantic links.
- Duplicate Agent: finds similar questions and recommends link, merge, fork, differentiate, or archive.
- Hypothesis Agent: generates testable hypotheses.
- Experiment Agent: suggests feasible experiment designs.
- Project Agent: converts questions into project plans.
- Game Agent: prepares game conversion concepts.
- Review Agent: checks safety, meaning preservation, and approval readiness.

## Agent Contract

Each agent declares purpose, inputs, outputs, permissions, failure modes, and evaluation criteria.
