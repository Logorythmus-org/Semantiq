# AI Collaboration

AI assists. Humans decide.

## Collaboration Modes
- AI pair programming
- AI research
- AI writing
- AI planning
- AI reviewing
- AI benchmarking
- AI translation
- AI presentation
- AI education
- AI scientific analysis

## Agent Roles
Planner Agent, Research Agent, Writing Agent, Code Agent, Review Agent, Scientific Agent, Benchmark Agent, Presentation Agent, Memory Agent, and Security Agent.

## Communication Architecture
Agents communicate through workspace events, task assignments, comments, suggestions, review requests, and workflow messages. Agents do not directly mutate internal state; they propose changes through commands and approval flows.

## Human Control
Workspace policies define which agent actions can run automatically, which require approval, and which are forbidden.
