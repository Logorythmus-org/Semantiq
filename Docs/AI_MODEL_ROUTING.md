# AI Model Routing

AI Model Routing chooses local, edge, or cloud models based on transparent policy.

## Model Families
Local LLM, cloud LLM, embedding models, vision models, speech models, reasoning models, tool models, and benchmark models.

## Routing Criteria
Latency, privacy, cost, capability, availability, user policy, workspace permissions, offline status, and historical performance.

## Policy
Cloud execution is never forced. Sensitive workspace data must remain local unless policy and human approval allow remote execution.

## Output
Routing decisions store selected model, alternatives, reasons, estimated cost, privacy impact, confidence, and fallback.
