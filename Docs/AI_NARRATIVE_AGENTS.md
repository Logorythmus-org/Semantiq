# AI Narrative Agents

AI narrative agents enhance creativity while preserving human oversight.

## Agents
Narrative Agent, Story Planner, Character Agent, Dialogue Agent, Game Designer Agent, Rule Generator, Puzzle Agent, Reflection Agent, Teacher Agent, Difficulty Balancer, Localization Agent, and Accessibility Agent.

## Agent Contract
Each agent defines purpose, inputs, outputs, capabilities, evaluation, failure modes, and permissions.

## Safety
No fabricated educational claims. Human review is required before publication.
