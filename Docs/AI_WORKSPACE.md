# AI Workspace

The AI Workspace embeds assistants and agents inside workspace context.

## Assistant Capabilities
Summarize, explain, review, translate, benchmark, generate, compare, research, write, code, teach, visualize, and suggest.

## Context
Assistants understand workspace, project, question, graph, repository, conversation, notebook, workflow, benchmark, memory, permission, and semantic wallet context.

## Boundaries
Agents act through Agent OS and must respect workspace permissions, approval policies, audit logging, and human oversight.
