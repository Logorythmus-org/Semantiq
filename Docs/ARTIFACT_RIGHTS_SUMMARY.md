# Public Artifact Rights Summary

> **Historical summary — not a blanket rights determination.** The matrix
> below reflects prior project policy assertions and is not sufficient proof of
> ownership, license compatibility, dataset provenance, or commercial readiness.
> See [`LICENSING.md`](../LICENSING.md) and
> [commercialization readiness](governance/commercialization-readiness.md).

This document provides a public-facing summary of artifact rights, open-source licenses, attribution guidelines, and limitations for **SemantIQ Benchmarks**.

## Summary Verdict

**Superseded historical characterization:** this document previously described
SemantIQ as an "open, unencumbered evaluation toolkit." The current repository
does **not** substantiate an unencumbered-rights finding for every asset or a
complete third-party dependency clearance. The root MIT license permits
commercial reuse where it applies; file-specific and third-party terms remain
controlling.
