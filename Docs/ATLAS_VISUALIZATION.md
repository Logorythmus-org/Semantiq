# Atlas Visualization

The Atlas requires interactive navigation.

## Views

Knowledge Graph, Timeline, Domain Map, Evidence Network, Research Progress, Uncertainty Heatmap, Question Clusters, Scientific Tree, Dependency Graph, and Discovery Paths.

## Performance

Large views use lazy loading, clustering, depth limits, streaming graph updates, cached projections, and offline snapshots.

## Rule

Visualization is a view over traceable data, not the source of truth.
