# Beta Readiness Release Gate Criteria

This document defines the release gate requirements for graduating from Public Alpha (`0.1.0-alpha.1`) to Public Beta (`0.2.0-beta.1`).

---

## Release Gate Checklist

| Requirement | Target SLA | Status |
|---|---|---|
| **Public Alpha Reliability** | 0 open release blockers | **PASSED** |
| **Community Infrastructure** | Code of Conduct & Issue Templates | **PASSED** |
| **Scientific Visibility** | DataCite v4.4 & OpenAlex metadata | **PASSED** |
| **Ecosystem Ecosystem** | Third-party pack validator & registry | **PASSED** |
| **Test Suite Passage** | 100% test passage | **PASSED** |
