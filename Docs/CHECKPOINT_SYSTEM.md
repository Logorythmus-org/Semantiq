# Checkpoint System

The Checkpoint System makes compute tasks recoverable.

## Capabilities

Pause, resume, rollback, recovery, migration, partial results, versioning, and distributed resume.

## Checkpoint Contents

Task state, resource state, input references, output references, partial results, logs, benchmark references, memory footprint, retry count, and restore instructions.

## Recovery

Recovery can restore on the same resource, migrate to another resource, fall back to a different strategy, or escalate to a human.
