# Collective Reasoning

Collective reasoning keeps distributed knowledge work explainable.

## Supported Reasoning

Distributed hypothesis building, collaborative argument mapping, evidence comparison, alternative perspectives, counterarguments, consensus formation, scientific debate, minority reports, and uncertainty mapping.

## Evidence First

Consensus summarizes state. It does not replace evidence, uncertainty, or minority reports.

## Explainability

Every reasoning path stores claims, evidence, assumptions, counterarguments, confidence, uncertainty, contributors, Semantiq references, and graph links.
