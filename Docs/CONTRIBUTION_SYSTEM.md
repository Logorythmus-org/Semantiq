# Contribution System

Every contribution becomes traceable.

## Contribution Types
Observation, evidence, experiment, code, dataset, review, comment, visualization, publication, translation, and teaching material.

## Contribution Fields
Author, timestamp, version, confidence, license, benchmark, relations, provenance, workspace/project scope, and audit reference.

## Integrity
Contributions are append-only. Corrections and retractions create new linked contributions.

## Community Contributions
Communities track questions, evidence, experiments, projects, reviews, code, datasets, games, narratives, publications, mentoring, teaching, moderation, translations, and visualizations.

Each community contribution stores author, timestamp, confidence, Semantiq score, relations, impact, license, and version. Community reputation derives from these explainable records, not likes or followers.
