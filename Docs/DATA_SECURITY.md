# Data Security

The Data Platform prepares security boundaries without binding to one identity provider.

## Capabilities
- encryption at rest
- encryption in transit
- permission model
- workspace isolation
- project isolation
- secret storage
- key rotation
- audit logs
- zero trust
- future semantic identity

## Isolation
Workspace and project scopes apply to storage, graph traversal, search indexes, vector queries, backups, exports, and sync.

## Audit
Sensitive data operations emit audit records with actor, scope, operation, object id, timestamp, correlation id, and result.
