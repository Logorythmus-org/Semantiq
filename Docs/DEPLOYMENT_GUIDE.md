# Deployment Guide

Tech Club deployment remains modular.

## Deployment Profiles

Local, Docker, desktop, browser, cloud, hybrid, enterprise, education, research, government, and community.

## Profile Fields

Runtime target, required modules, optional modules, storage mode, sync mode, authentication mode, integration adapters, observability, security controls, backup, rollback, and update policy.

## Principle

No deployment profile should require unrelated platform subsystems. Local-first operation remains the baseline.
