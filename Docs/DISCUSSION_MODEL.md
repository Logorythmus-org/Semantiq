# Discussion Model

Discussion is semantic, not linear.

## Contribution Types
Questions, counter questions, observations, evidence, references, experiments, hypotheses, ideas, challenges, and reviews.

## Knowledge Object Rule
Every contribution becomes a Knowledge Object with identity, metadata, versioning, relations, permissions, history, tags, and graph links.

## Structure
Discussion graphs show how claims, evidence, objections, hypotheses, and experiments relate. This replaces shallow comment threads.
