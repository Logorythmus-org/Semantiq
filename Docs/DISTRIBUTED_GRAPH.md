# Distributed Graph

The distributed graph spans multiple autonomous knowledge nodes.

## Supported References

Cross-node relations, knowledge references, remote questions, remote evidence, distributed communities, distributed research, distributed workflows, distributed assets, and benchmark references.

## Traceability

Every distributed relation stores source node, target node, object reference, relation type, provenance, version, trust, and policy metadata.

## Integrity

Remote references never overwrite local graph state. They extend it with traceable external context.
