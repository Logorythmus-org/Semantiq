# Distributed Runtime

Distributed execution is optional, local-first, and provider-independent.

## Execution Topologies

Single device, multiple CPUs, multiple GPUs, browser mesh, LAN cluster, remote node, hybrid execution, future internet mesh, and future volunteer network.

## Strategies

Sequential, parallel, pipeline, map, reduce, scatter, gather, graph execution, recursive execution, adaptive execution, and checkpoint recovery.

## Boundaries

No workflow requires cloud execution. Remote nodes must pass capability, health, permission, trust, and policy checks before receiving work.

## Failure Handling

Distributed failures can retry, migrate, fall back, restore checkpoints, escalate to humans, complete partially, choose alternative resources, or shut down gracefully.
