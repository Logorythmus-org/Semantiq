# Document System

The Workspace Runtime uses a unified document architecture.

## Document Types
Markdown, rich text, scientific paper, notebook, code, JSON, YAML, diagram, canvas, mind map, presentation, tables, mathematical expressions, and interactive blocks.

## Executable Documents
Documents can be executable when they contain notebooks, code blocks, diagrams, queries, workflows, benchmarks, or interactive blocks.

## Collaboration
Documents support presence, cursor sharing, selection sharing, comments, annotations, suggestions, review, history, time travel, offline editing, and merge.

## Graph Integration
Document edits can update knowledge objects, citations, evidence links, question links, project maps, and timeline entries.
