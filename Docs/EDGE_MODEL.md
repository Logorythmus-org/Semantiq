# Edge Model

Knowledge edges represent semantic relations between graph nodes.

## Relations
Supported relations include answers, extends, supports, contradicts, belongs_to, depends_on, references, inspired_by, generated_by, validated_by, improves, teaches, requires, and funds.

## Edge Fields
Each edge stores identity, source, target, relation, confidence, weight, timestamp, evidence, version, metadata, and audit IDs.

Edges require existing source and target nodes and cannot self-target.
