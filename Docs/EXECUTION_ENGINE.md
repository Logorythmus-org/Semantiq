# Execution Engine

The Execution Engine runs workflows deterministically.

## Supported Execution Concepts

- Sequential execution.
- Parallel execution contracts.
- Distributed execution contracts.
- Interruptible workflows.
- Retry and recovery strategy.
- Resume and rollback strategy.
- Checkpoints.
- Nested workflow contracts.
- Streaming execution contracts.
- Background task contracts.

The current local runtime executes deterministic workflows and blocks privileged nodes until human approval is present.
