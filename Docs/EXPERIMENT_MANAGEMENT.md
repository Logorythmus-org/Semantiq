# Experiment Management

Experiments are managed through a transparent lifecycle.

## Lifecycle

Idea -> Protocol -> Preparation -> Execution -> Data Collection -> Analysis -> Replication -> Review -> Publication -> Future Improvements.

## Stored Data

Protocols, variables, measurements, equipment, software, datasets, results, limitations, evidence links, repositories, benchmark records, and future work.

## Rule

Negative and inconclusive experiments are preserved because they improve scientific understanding.
