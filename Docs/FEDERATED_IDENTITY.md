# Federated Identity

Federated identity supports cross-node authentication without erasing privacy.

## Identity Types

Personal identity, organization identity, node identity, agent identity, workspace identity, and community identity.

## Authentication

Cross-node authentication uses signed node identity, protocol compatibility, permission scopes, trust records, and privacy-preserving claims.

## Wallet Integration

Semantic Wallet records can prove credentials, licenses, trust, achievements, and contribution proofs without centralizing private identity data.
