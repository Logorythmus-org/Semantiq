# Public Feedback Triage Taxonomy

This document defines the categorization taxonomy for community feedback submitted to **SemantIQ Benchmarks**.

---

## Triage Categories

| Category                    | Description                                    | SLA Target        |
| --------------------------- | ---------------------------------------------- | ----------------- |
| `bug-report`                | Code defect, unexpected error, runtime failure | 48 Hours          |
| `benchmark-request`         | Proposal for new evaluation benchmark packs    | 5 Business Days   |
| `connector-request`         | Feature request for new LLM model backend      | 5 Business Days   |
| `reproducibility-issue`     | Score discrepancy across independent runs      | 24 Hours (Urgent) |
| `documentation-improvement` | Clarification or fix in guides/APIs            | 7 days            |
| `feature-proposal`          | Architectural or capability suggestion         | 14 Days           |
