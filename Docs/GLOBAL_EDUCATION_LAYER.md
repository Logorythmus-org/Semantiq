# Global Education Layer

The Global Education Layer helps civilization teach itself from preserved knowledge.

## Generated Materials

Courses, books, lessons, games, workshops, research guides, learning paths, curricula, explanations, assessments, and historical learning journeys.

## Source Integrity

Educational materials reference source questions, evidence, lineage, provenance, Semantiq evaluations, historical context, and governance constraints.

## Accessibility

Education artifacts should be reusable across languages, regions, ages, abilities, and offline environments.
