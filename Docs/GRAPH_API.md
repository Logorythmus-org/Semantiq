# Graph API

The Knowledge Intelligence Layer exposes these API contracts:

- `createNode()`
- `createEdge()`
- `searchKnowledge()`
- `analyzeQuestion()`
- `runSemantiq()`
- `recommendKnowledge()`
- `findRelations()`
- `getTimeline()`
- `compareKnowledge()`
- `explainScore()`

API contracts remain storage-independent and can be surfaced through REST, GraphQL, MCP, and internal services.
