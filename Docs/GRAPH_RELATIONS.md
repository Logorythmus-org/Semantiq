# Graph Relations

Core graph relations include:

- `answers`
- `extends`
- `contradicts`
- `supports`
- `references`
- `derived_from`
- `generated_by`
- `funded_by`
- `belongs_to`
- `improves`
- `requires`
- `teaches`

Every relation includes identity, source, target, type, metadata, creator, timestamp, and version. Relations are storage-independent and emitted through domain events.
