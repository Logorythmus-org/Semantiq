# Identity Architecture

Identity is a first-class concept in Tech Club. It applies to people, AI agents, projects, communities, knowledge, questions, repositories, workspaces, games, books, semantic assets, plugins, workflows, and benchmarks.

## Security Layers

- User: human or system actor.
- Identity Layer: stable semantic identities for actors and objects.
- Authentication: replaceable proof that an actor controls an identity.
- Authorization: explainable decision for an action.
- Capability Engine: object-specific available actions.
- Permission Engine: composable permission grants.
- Policy Engine: declarative rules over context and attributes.
- Semantic Wallet: ownership, credentials, achievements, licenses, and signatures.
- Audit Layer: immutable security and ownership history.
- Encrypted Storage: local-first protection for secrets and wallet records.
- Infrastructure: kernel, data platform, integration adapters, and future distributed runtime.

## Universal Identity Model

Every identity includes UUID, semantic URI, version, owner, visibility, trust level, verification status, creation history, audit history, permissions, and relationships.

## Identity Subjects

User, AI Agent, Workspace, Project, Question, Repository, Knowledge Object, Game, Narrative, Dataset, Research, Organization, Community, Wallet, Plugin, Workflow, and Benchmark.

## Local-First Rule

Users can own and use local identities without mandatory cloud identity providers.
