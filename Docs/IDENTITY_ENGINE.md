# Identity Engine

The Identity Engine implements reusable identity aggregates for humans, agents, workspaces, organizations, wallets, federation identities, trust, verification, roles, permissions, and audit.

The first production slice exposes `IdentityAggregate`, identity factories, repository contracts, an application service, validation, and memory repository support.

Identity remains reusable across workspace, question, knowledge, graph, permission, event, federation, marketplace, and civilization layers.
