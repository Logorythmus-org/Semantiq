# Knowledge Evolution

Knowledge changes over time and is never overwritten.

## Evolution Path
Question -> Observation -> Evidence -> Hypothesis -> Experiment -> Replication -> Peer Discussion -> Project -> Publication -> Consensus -> New Questions.

## Traceability
Every evolution step records actor, timestamp, source object, target object, explanation, confidence, and version.

## Append-Only Rule
Corrections create new timeline entries. Prior claims remain available for audit, history, and learning.
