# Knowledge Gap Engine

The Knowledge Gap Engine converts missing knowledge into actionable collaboration.

## Gap Types
Missing evidence, experiments, communities, disciplines, datasets, collaborators, educational resources, research, and questions.

## Gap Records
Each gap stores source questions, affected communities, evidence state, missing resources, confidence, urgency, Semantiq references, graph links, and recommended next actions.

## Actionability
Every gap can become a research opportunity, community request, workflow, funding target, educational resource request, or agent task.
