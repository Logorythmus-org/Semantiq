# Knowledge Graph Runtime

The Knowledge Graph is alive while the workspace is open.

## Capabilities

Real-time updates, semantic navigation, question clusters, evidence maps, project maps, repository maps, agent maps, timeline views, filtering, search, large graph rendering, and graph editing.

## Projections

Graph projections can focus on questions, projects, repositories, workflows, agents, research, narratives, execution, benchmarks, and timelines.

## Performance

Large graph views require virtual rendering, incremental loading, streaming updates, background indexing, and future GPU rendering.
