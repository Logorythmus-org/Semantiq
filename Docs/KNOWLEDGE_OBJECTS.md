# Knowledge Objects

Everything inside a workspace is a Knowledge Object.

## Examples
Question, Answer, Observation, Idea, Hypothesis, Experiment, Task, Goal, Repository, Dataset, Notebook, Conversation, Workflow, Diagram, Mind Map, Presentation, Research Paper, Book, Video, Audio, Game, and Benchmark.

## Common Model
Every knowledge object supports:
- identity
- metadata
- versioning
- relations
- permissions
- agent notes
- comments
- history
- tags
- semantic links
- benchmark results

## Graph Participation
Knowledge objects automatically project into the workspace knowledge graph as semantic nodes and relationships.

## Reuse
Knowledge objects can move across projects, be linked into multiple workspaces, forked, restored, exported, and indexed.
