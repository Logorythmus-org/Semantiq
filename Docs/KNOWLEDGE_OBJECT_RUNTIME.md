# Knowledge Object Runtime

Knowledge objects are the unified executable units of the workspace.

## Supported Objects
Question, project, document, notebook, repository, dataset, diagram, canvas, mind map, presentation, workflow, conversation, game, narrative, research paper, publication, evidence, and experiment.

## Object Capabilities
Identity, relations, version, permissions, comments, history, benchmark references, agent context, live collaboration, graph projection, search indexing, and timeline activity.

## Execution
Executable objects can launch notebooks, workflows, repository tasks, benchmarks, visualizations, AI agents, or graph updates while preserving workspace context.
