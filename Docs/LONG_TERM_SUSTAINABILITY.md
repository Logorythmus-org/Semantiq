# Long-Term Sustainability

Tech Club must survive organizational, technical, economic, and cultural change without requiring a full redesign.

## Sustainability Areas

- Knowledge preservation.
- Financial sustainability.
- Community sustainability.
- Developer sustainability.
- Research sustainability.
- Governance sustainability.
- Infrastructure sustainability.

## Constraints

No subsystem should depend on one organization, cloud, model provider, blockchain, database, programming language, protocol, or funding source.

## Operating Pattern

Sustainability reviews should produce questions, health metrics, risks, mitigation plans, protocol updates, migration plans, and public reports.
