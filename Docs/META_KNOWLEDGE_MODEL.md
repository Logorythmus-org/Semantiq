# Meta Knowledge Model

The Meta Knowledge Model gives every important Tech Club object a unified semantic identity while preserving module ownership.

## Object Types

The kernel recognizes questions, knowledge, evidence, research, experiments, publications, communities, institutions, organizations, people, agents, workflows, education, innovation, policies, marketplace assets, governance processes, challenges, roadmaps, and civilization memory.

## Required Fields

Every meta knowledge object includes:

- Stable object identity.
- Object type.
- Semantic identity.
- Originating question.
- Title.
- Contributors.
- Provenance.
- Evidence.
- Semantiq benchmark links.
- Policy links.
- Creation and update timestamps.

## Ownership

The kernel stores coordination references and graph-level semantics. Domain modules remain the source of truth for their own objects.

## Continuity

Objects must remain portable across storage engines, AI providers, schemas, organizations, protocols, and future runtime environments.
