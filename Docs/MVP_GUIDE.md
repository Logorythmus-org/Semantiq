# MVP Guide

The Tech Club MVP is an integrated AI-native Open Knowledge Operating System.

## MVP Includes

- Semantic Workspace
- Social Question Network
- Question Intelligence
- Semantiq Benchmark
- Scientific Atlas
- Research Projects
- Narrative Learning
- Community Intelligence
- Agent OS
- Workflow Engine
- Distributed Runtime
- Semantic Marketplace
- Developer SDK
- Knowledge Graph
- Semantic Wallet
- Search
- Offline Runtime

## Release Readiness

The MVP is releasable when every module is integrated, no duplicated architecture remains unresolved, Knowledge Graph links are complete, Agent OS works, Workflow Engine works, Marketplace works, Developer SDK works, offline-first remains functional, security passes validation, and documentation is complete.
