# MVP User Journey

The MVP acceptance journey is implemented in `LocalMvpRuntime.runMvpJourney()`.

1. User creates local identity.
2. User creates workspace.
3. User creates question.
4. Question Intelligence analyzes and improves the question.
5. User approval is represented by suggestion approval.
6. Semantiq evaluates the question.
7. Knowledge Graph creates the question node.
8. User converts the question into a research project.
9. User adds evidence.
10. Agent OS creates a goal from the research project.
11. Workflow runtime generates a simple research workflow.
12. Agent executes one workflow.
13. Community is created around the question.
14. Dashboard displays progress.
15. Workspace exports as a portable JSON plus Markdown summary structure.
