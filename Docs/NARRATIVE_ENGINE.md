# Narrative Knowledge Engine

The Narrative Knowledge Engine transforms questions into interactive learning experiences. It is not a generic game engine and not a generic storytelling engine.

## Core Flow
Question -> Knowledge Graph -> Narrative Structure -> Interactive Story -> Educational Game -> Reflection -> Knowledge Reinforcement -> New Questions.

## Outputs
Stories, learning adventures, interactive books, card games, board games, role-playing games, classroom activities, escape rooms, scientific simulations, historical reconstructions, business simulations, and collaborative challenges.

## Rule
Every narrative, game, card, challenge, decision, and reflection remains connected to the originating question and knowledge graph.

## Package Layout
- `packages/narrative-engine/src/contracts.ts`: narrative, story, scene, character, game, role, card, decision, reflection, learning, agent, repository, service, and event contracts.
- `packages/narrative-engine/src/index.ts`: local repository/service scaffold.
- Future directories: `stories/`, `characters/`, `dialogues/`, `scenes/`, `cards/`, `games/`, `roles/`, `rules/`, `puzzles/`, `reflection/`, `education/`, `agents/`, `benchmark/`, `knowledge/`, `api/`, `events/`, `schemas/`, `ui/`, `tests/`, and `docs/`.
