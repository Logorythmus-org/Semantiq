# Notebooks

Scientific notebooks combine thinking, execution, data, experiments, and AI assistance.

## Supported Content
Markdown, code, charts, benchmarks, experiments, datasets, AI assistance, versioning, execution history, and export.

## Execution History
Every execution records input, output, environment, dataset references, benchmark references, agent involvement, timestamp, and reproducibility metadata.

## Graph Integration
Notebook cells and outputs can become knowledge objects and graph nodes when promoted or referenced.
