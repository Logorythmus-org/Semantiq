# Notebook Runtime

The Notebook Runtime supports reproducible research and executable analysis inside the workspace.

## Cell Types

Markdown, Python, JavaScript, SQL, visualization, chart, data analysis, experiment, AI assistance, benchmark, and graph query cells.

## Execution

Notebook execution records cell inputs, outputs, dependencies, datasets, benchmark references, experiment links, graph updates, errors, and history.

## Reproducibility

Notebooks preserve environment references, data versions, execution order, results, and provenance.

## Offline Mode

Offline notebooks use local kernels, local datasets, cached graph context, and deferred external calls.
