# Observability

Compute observability makes every resource and task visible.

## Monitored Areas

Workers, schedulers, queues, resources, GPU, CPU, WebGPU, memory, agents, execution, network, health, failures, checkpoints, model routing, and optimization.

## Views

Compute dashboard, scheduler view, resource explorer, GPU monitor, WebGPU inspector, execution timeline, task queue, cluster view, performance charts, runtime console, health monitor, and optimization panel.

## Events

Resource registration, availability, scheduling, start, completion, failure, checkpointing, restoration, optimization, benchmarking, scaling, and archive events are observable.

## System Dashboards

Runtime, performance, errors, knowledge growth, communities, agents, marketplace, developers, security, infrastructure, analytics, release, and roadmap dashboards provide MVP readiness visibility.
