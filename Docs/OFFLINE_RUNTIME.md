# Offline Runtime

The Workspace Runtime is offline-first.

## Offline Capabilities

Offline editing, offline search, offline AI, offline Knowledge Graph, offline repository access, offline notebooks, offline synchronization, conflict resolution, and local ownership.

## Deferred Work

External calls, remote sync, cloud AI, shared collaboration, and publication can be queued as explicit pending actions.

## Local Ownership

Local workspace state remains usable, auditable, searchable, and versioned even when disconnected.
