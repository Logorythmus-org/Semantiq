# Optimization Engine

The Optimization Engine improves workflows using execution evidence.

## Signals
Execution time, agent usage, failures, costs, parallelization, knowledge density, benchmark history, recovery events, approval bottlenecks, and template reuse.

## Recommendations
Recommendations can suggest parallelization, node removal, retry policy changes, better agents, safer approval placement, cheaper tools, richer validation, or clearer templates.

## Constraints
Optimization suggestions do not automatically rewrite published workflows without approval.
