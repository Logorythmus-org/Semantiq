# Package Engineering Standard

Every production package follows the same layout once implementation begins:

- `README.md`
- `package.json`
- `src/`
- `tests/`
- `examples/`
- `docs/`
- `spec/`
- `tasks/`
- `contracts/`
- `adr/`
- `spec-history/`
- `CHANGELOG.md`
- API notes
- Architecture notes
- Benchmark notes where applicable
- Coverage expectations

Bootstrap packages may contain only the minimum source-controlled scaffold until their feature Spec-Kit is approved.
