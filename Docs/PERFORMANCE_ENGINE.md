# Performance Engine

The Performance Engine measures and improves compute execution.

## Metrics
CPU usage, GPU usage, WebGPU usage, memory, latency, energy, task throughput, success rate, queue length, scheduling efficiency, and knowledge produced.

## Optimization
Performance history informs scheduling, model routing, resource benchmarking, memory management, queue policy, fallback behavior, and future task planning.

## Semantiq
Semantiq evaluates execution quality, resource efficiency, planning quality, optimization, reliability, scalability, energy efficiency, and knowledge produced.
