# Planetary Education Network

The Planetary Education Network makes education the natural consequence of living knowledge. It is a Human Development Operating System, not a fixed curriculum product.

## Core Flow
Question -> Curiosity -> Learning -> Practice -> Research -> Mastery -> Teaching -> Mentoring -> Civilization Knowledge -> Next Generation.

## Responsibilities
- Generate adaptive learning paths from questions.
- Track competencies as semantic evidence.
- Connect learners, mentors, teachers, projects, research, games, narratives, and communities.
- Issue verifiable credentials based on demonstrated capability.
- Support global classrooms and accessible offline learning.

## Package Layout
- `packages/education-network/src/contracts.ts`: learning objects, paths, competencies, mentorship, teaching, assessments, credentials, analytics, agents, classrooms, repository, service, and event contracts.
- `packages/education-network/src/index.ts`: local service scaffold for learning paths, recommendations, competency tracking, mentorship, courses, lessons, assessment, credentials, verification, and analytics.
- Future directories: `learning/`, `competencies/`, `paths/`, `courses/`, `assessment/`, `credentials/`, `mentorship/`, `teaching/`, `analytics/`, `classrooms/`, `accessibility/`, `agents/`, `portfolio/`, `api/`, `events/`, `contracts/`, `schemas/`, `ui/`, `tests/`, and `docs/`.
