# Preprint Preparation & Citation Guide

This guide provides paper templates and citation guidelines for researchers citing **SemantIQ Benchmarks** in preprints submitted to arXiv, bioRxiv, or medRxiv.

---

## Standard Methodological Paragraph

> "Model evaluations were conducted using SemantIQ Benchmarks (Version 0.1.0-alpha.1) running in local-first, deterministic mode. Evaluated dimensions include reasoning quality, semantic consistency, and evidence grounding, with raw execution outputs preserved for 100% reproduction."
