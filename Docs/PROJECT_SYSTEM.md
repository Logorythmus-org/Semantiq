# Project System

Projects are semantic ecosystems derived from questions. They organize meaning, work, evidence, collaboration, and outcomes.

## Project Contents
Projects may contain questions, goals, milestones, tasks, repositories, documents, datasets, benchmarks, agents, workflows, narratives, games, experiments, and publications.

## Project Dashboard
Every project exposes overview, goals, questions, progress, milestones, tasks, repositories, benchmarks, agents, resources, knowledge graph, recent activity, and health status.

## Project Rules
- Projects are not folders.
- Every project object is a knowledge object.
- Projects can move forward and backward through lifecycle states.
- Projects connect to questions and graph relationships.
- Projects can be forked, archived, restored, benchmarked, published, or kept private according to policy.
