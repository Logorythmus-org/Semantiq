# Prompt Library

Prompt templates are versioned artifacts stored in `packages/question-intelligence/prompts/`.

## Required Templates

- `question-refinement.prompt.md`
- `intent-extraction.prompt.md`
- `ambiguity-analysis.prompt.md`
- `assumption-detection.prompt.md`
- `tagging.prompt.md`
- `duplicate-detection.prompt.md`
- `relation-suggestion.prompt.md`
- `evidence-suggestion.prompt.md`
- `hypothesis-generation.prompt.md`
- `experiment-suggestion.prompt.md`
- `question-to-project.prompt.md`
- `question-to-game.prompt.md`
- `semantiq-preview.prompt.md`
- `review.prompt.md`

## Rules

Prompts must preserve user meaning, expose uncertainty, avoid fabricated evidence, and require user approval for changes.
