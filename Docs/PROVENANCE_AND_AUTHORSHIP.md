# Provenance & Authorship Framework

This document outlines the cryptographic and metadata mechanisms used to track provenance and authorship for **SemantIQ Benchmarks**.

---

## 1. Provenance Records

Every benchmark evaluation report generated by SemantIQ includes an immutable provenance block:

```json
{
  "artifactId": "semantiq:evaluation-report:rpt-2026-07-31:a1b2c3d4",
  "contentHash": "00112233445566778899aabbccddeeff...",
  "gitCommit": "a1b2c3d4e5f6789...",
  "creators": [{ "name": "LocalSemantiqEngine" }],
  "provenance": {
    "generatedBy": "semantiq-engine-v0.1.0"
  }
}
```

---

## 2. Integrity Verification

Subsequent consumers can verify report authenticity by re-computing the SHA-256 content hash using `computeContentHash()`.
