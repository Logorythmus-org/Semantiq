# Public API

Public APIs make Tech Club programmable without exposing internal boundaries.

## API Families
REST, GraphQL, WebSocket, event streams, CLI, MCP, SDK, batch APIs, streaming APIs, and versioned APIs.

## Requirements
Every API is documented, versioned, authenticated, authorized, rate-limited, observable, auditable, and covered by compatibility policy.

## Stability
Breaking changes require new versions, migration guides, deprecation windows, and compatibility tests.
