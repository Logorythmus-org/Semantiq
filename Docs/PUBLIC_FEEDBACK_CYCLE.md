# Public Feedback Cycle Process Guide

This document outlines the public feedback intake, triage, synthesis, decision-making, and roadmap update workflow for **SemantIQ Benchmarks**.

---

## 1. Process Lifecycle

```text
Community Feedback Submitted (GitHub Issues / Discussions)
├── Triage & Categorization (Feedback Taxonomy)
├── Automated Synthesis & Synthesis Reports
├── Product Decision Record (PDR) Creation
└── Public Roadmap Update & Implementation
```

---

## 2. Privacy & Sanitization

All submitted feedback is sanitized locally via `submitPublicFeedback()` to ensure no personal tokens, API keys, or private identifiers are stored.
