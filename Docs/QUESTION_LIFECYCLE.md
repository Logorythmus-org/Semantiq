# Question Lifecycle

Questions continuously evolve.

## Lifecycle
Idea -> Draft -> Published -> Discussion -> Evidence Collection -> Research -> Experiment -> Project -> Publication -> Archive.

## Reversibility
The lifecycle is reversible. A published question can return to evidence collection. A research question can become discussion again when contradictions appear. Archived questions can be restored by policy.

## Events
Lifecycle changes publish versioned events and update profile, graph, feed, analytics, search, and benchmark projections.
