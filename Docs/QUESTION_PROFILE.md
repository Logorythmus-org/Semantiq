# Question Profile

Every question automatically generates a living semantic profile.

## Profile Sections

- summary
- context
- knowledge graph
- evidence
- counter evidence
- open problems
- unknowns
- assumptions
- dependencies
- contradictions
- related questions
- related projects
- related papers
- benchmarks
- semantic timeline
- AI insights
- future directions
- question health

## Evolution

Profiles evolve from events: evidence added, hypotheses proposed, relations created, benchmarks completed, discussions updated, projects linked, and agent suggestions approved.

## Rule

Question profiles are projections. The source of truth remains question aggregate state, knowledge objects, relationships, and benchmark records.
