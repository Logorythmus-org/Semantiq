represent a stable SemantIQ software release.

Some files in `Docs/` preserve historical, planning, migration, or subsystem
context. Their presence does not automatically make them canonical current
product documentation. Canonical public claims should follow the current
documentation index, versioning policy, known limitations, and directly cited
implementation evidence.
