# Release Process

Release is the start of learning, not the end of architecture.

## Pipeline
Build -> Tests -> Benchmarks -> Security Scan -> Package -> Documentation -> Release Candidate -> MVP -> Stable -> LTS -> Continuous Delivery.

## Release Candidate
Release candidates include system map, validation report, health report, security report, performance report, documentation report, deployment profiles, changelog, release notes, and rollback plan.

## Human Approval
Public releases require human approval after validation, security review, documentation verification, and release note review.
