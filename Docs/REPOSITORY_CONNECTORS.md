# Repository Connectors

Repository connectors adapt code and dataset repositories into Tech Club.

## Providers
- GitHub
- GitLab
- Local Git
- Azure DevOps
- future repository providers

## Operations
Clone, commit, push, pull, branch, merge, history, search, issues, pull requests, and releases.

## Rules
Repository providers expose provider-neutral operations. Provider-specific issue, pull request, and release fields are mapped into adapter-safe metadata.
