# Repository Templates

Every repository area, package, app, service, agent, plugin, and SDK must declare its production responsibility before implementation.

## Package Template

```md
# <Package Name>

## Purpose

## Responsibility

## Owner

## Dependencies

## Public APIs

## Interfaces

## Events

## Schemas

## Tests

## Benchmarks

## Examples

## Documentation

## Version

## Release Status
```

```md
# <Service Name>

## Configuration

## Health Checks

## Runbook
```
