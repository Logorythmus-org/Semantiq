# Reputation Engine

Reputation is explainable evidence of knowledge contribution. It is not popularity.

## Reputation Sources

Question quality, evidence quality, scientific thinking, teaching, collaboration, review quality, project contributions, innovation, community support, mentoring, and research integrity.

## Forbidden Sources

Likes, followers, popularity, and virality.

## Rule

Every reputation record includes source contribution, Semantiq signal, explanation, confidence, and audit reference.
