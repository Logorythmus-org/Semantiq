# Research Engine

The Collaborative Research Engine transforms questions into reproducible, collaborative, transparent scientific projects.

## Core Flow

Question -> Investigation -> Evidence -> Hypothesis -> Experiment -> Research Project -> Publication -> Innovation -> Public Knowledge.

## Objectives

Question-driven research, collaborative investigation, evidence collection, hypothesis tracking, experiment management, research teams, peer review, version history, publications, benchmarking, analytics, and innovation tracking.

## Rule

This is not Jira, Trello, or generic project management. Every research project remains connected to its originating questions, evidence, hypotheses, experiments, publications, benchmarks, and knowledge graph.

## Package Layout

- `packages/research-engine/src/contracts.ts`: project, team, contribution, workflow, evidence, hypothesis workspace, experiment, review, publication, analytics, innovation, agent, repository, service, and event contracts.
- `packages/research-engine/src/index.ts`: local repository/service scaffold.
- Future directories: `projects/`, `teams/`, `contributions/`, `evidence/`, `hypotheses/`, `experiments/`, `reviews/`, `publications/`, `analytics/`, `innovation/`, `agents/`, `dashboard/`, `workflow/`, `timeline/`, `schemas/`, `events/`, `api/`, `ui/`, `tests/`, and `docs/`.
