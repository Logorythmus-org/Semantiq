# Research Project Model

Every Research Project begins from one or more Questions.

## Project Fields

Identity, research goal, original questions, scope, objectives, milestones, tasks, evidence, hypotheses, experiments, datasets, repositories, agents, researchers, contributors, organizations, communities, timeline, optional budget, resources, benchmarks, risks, ethics, publications, outcomes, and future work.

## Lifecycle

Question -> Investigation -> Planning -> Evidence Collection -> Hypothesis Formation -> Experiment -> Validation -> Peer Review -> Publication -> Community Review -> Project Evolution -> Archive.

## Branching

Projects never truly end. New discoveries can create branches, related projects, reopened questions, or new Atlas entries.
