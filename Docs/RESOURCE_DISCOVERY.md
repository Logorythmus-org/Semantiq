# Resource Discovery

Resource discovery identifies and validates compute resources.

## Discovery Modes
Automatic discovery, manual registration, capability matching, version compatibility, health validation, trust validation, resource benchmarking, and dynamic updates.

## Discovery Records
Records include resource identity, capability manifests, health status, benchmark results, permission scope, trust state, and last-seen timestamp.

## Dynamic Updates
Resources can change availability, health, power, latency, memory, temperature, or capability at runtime. Scheduler decisions must account for the latest validated state.
