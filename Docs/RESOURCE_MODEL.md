# Resource Model

Compute resources are semantic entities in Tech Club.

## Resource Fields
Identity, capabilities, hardware, software, performance, availability, permissions, power profile, cost, temperature, memory, latency, reliability, benchmark history, health, and runtime status.

## Resource Types
CPU, GPU, WebGPU, browser worker, Node worker, Docker worker, Python worker, inference worker, storage worker, graph worker, search worker, benchmark worker, rendering worker, simulation worker, and custom worker.

## Capability Advertising
Resources publish capability manifests with versions, limits, permissions, health, benchmark references, and supported execution strategies.

## Trust
Resources are not trusted by default. Remote and shared resources require trust validation, zero-trust communication, and workspace isolation.
