# Runtime Monitoring

Runtime monitoring gives users and operators visibility into active execution.

## Tracked Signals

Running agents, execution time, success rate, failures, costs, memory usage, tool usage, workspace activity, knowledge produced, benchmark scores, and system health.

## Views

Goal Planner, Execution Dashboard, Agent Monitor, Workflow Timeline, Agent Inspector, Task Graph, Memory Viewer, Reflection Viewer, Runtime Console, Agent Collaboration Panel, Execution Logs, Knowledge Timeline, and Benchmark Viewer.

## Health Model

Runtime health combines agent health, task progress, failure rate, approval blockers, cost drift, memory pressure, tool error rates, graph sync status, and Semantiq benchmark status.
