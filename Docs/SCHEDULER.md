# Scheduler

The Workflow Scheduler controls when workflows execute.

## Schedule Types

Immediate, delayed, cron, event-based, manual, recurring, calendar-based, dependency-based, and AI-generated schedules.

## Scheduling Rules

Schedules reference workflow versions, workspace permissions, required agents, tool availability, approval checkpoints, offline status, and dependency readiness.

## Safety

AI-generated schedules must explain why the timing is appropriate and must not bypass approval requirements.
