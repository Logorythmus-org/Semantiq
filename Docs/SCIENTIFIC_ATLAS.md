# Scientific Question Atlas

The Scientific Question Atlas is a living map of humanity's unanswered questions, evolving knowledge, scientific discoveries, and collaborative exploration.

## Core Flow

Question -> Observations -> Evidence -> Hypotheses -> Experiments -> Discussion -> Benchmark -> Projects -> New Questions.

## Primary Objectives

- map global knowledge
- connect related questions
- track scientific uncertainty
- reveal knowledge gaps
- visualize progress
- connect disciplines
- recommend future research
- support AI reasoning
- support collaborative discovery
- support education and innovation

## Rule

The Atlas is not an encyclopedia and not a database of answers. Knowledge evolves; previous states remain traceable.

## Package Layout

- `packages/scientific-atlas/src/contracts.ts`: Atlas entries, domains, states, evidence, hypotheses, experiments, timelines, uncertainty, recommendations, bridges, repository, and service contracts.
- `packages/scientific-atlas/src/index.ts`: local contract scaffold for validation.
- Future directories: `atlas/`, `entries/`, `domains/`, `knowledge/`, `evidence/`, `hypotheses/`, `experiments/`, `timeline/`, `uncertainty/`, `recommendations/`, `visualization/`, `search/`, `graphs/`, `agents/`, `api/`, `schemas/`, `events/`, `ui/`, `tests/`, and `docs/`.
