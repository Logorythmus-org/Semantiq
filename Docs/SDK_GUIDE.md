# SDK Guide

Tech Club SDKs expose identical platform concepts across languages.

## Target Languages
TypeScript, Python, Rust, Go, C#, Java, Kotlin, Swift, and future languages.

## Core Modules
Workspace SDK, Question SDK, Knowledge Graph SDK, Semantiq SDK, Workflow SDK, Agent SDK, Repository SDK, Community SDK, Marketplace SDK, Identity SDK, Wallet SDK, Storage SDK, Search SDK, Events SDK, and Benchmark SDK.

## Compatibility
SDKs follow semantic versioning, API compatibility policy, migration guides, deprecation windows, and LTS releases.

## Principle
SDKs expose public contracts and extension points. They do not expose internal event buses, aggregate internals, or storage internals.
