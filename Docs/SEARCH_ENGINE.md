# Search Engine

The Search Engine supports provider-abstract knowledge search.

## Modes
- Semantic search.
- Hybrid search.
- Keyword search.
- Question search.
- Knowledge search.
- Graph search.
- Similarity search.
- Timeline search.
- Workspace search.
- Federated search adapter.

The current graph runtime includes deterministic local search over node titles, labels, properties, and metadata. Production providers can add PostgreSQL, Neo4j, Meilisearch, OpenSearch, SQLite, and memory adapters.
