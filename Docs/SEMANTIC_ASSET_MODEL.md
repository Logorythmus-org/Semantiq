# Semantic Asset Model

Semantic assets are reusable knowledge objects with ownership, license, provenance, trust, and benchmark context.

## Asset Fields
Identity, title, description, creator, contributors, source questions, projects, Knowledge Graph links, Semantiq scores, license, ownership, version, dependencies, usage rights, price, access model, reputation, trust, and audit history.

## Asset Types
Question pack, research report, dataset, workflow template, AI agent, prompt pack, educational game, knowledge card deck, narrative book, scientific atlas entry, experiment protocol, repository template, presentation, course, community toolkit, and benchmark profile.

## Quality Signals
Semantiq score, evidence quality, creator reputation, community reviews, usage history, version history, license clarity, safety review, educational value, and research value.

## Provenance
Every asset links back to source questions, projects, contributors, graph nodes, versions, dependencies, audit records, and contribution proofs.
