# Semantic Digital Economy

The Semantic Digital Economy turns knowledge into reusable innovation. It is not an NFT shop, gig platform, or popularity marketplace.

## Core Flow

Question -> Knowledge -> Contribution -> Semantic Asset -> Reuse -> Innovation -> Public Benefit.

## Responsibilities

- Create and publish semantic assets.
- Attach machine-readable licenses.
- Track ownership, attribution, contribution proofs, revenue records, and audit history.
- Enable marketplace discovery based on Semantiq, trust, evidence, usage, license clarity, educational value, and research value.
- Support funding, donations, sponsorships, public goods, and revenue sharing.
- Integrate with Semantic Wallet without making wallet internals marketplace-owned.

## Package Layout

- `packages/semantic-economy/src/contracts.ts`: assets, listings, licenses, ownership, revenue shares, transactions, funding, reviews, search, marketplace agents, repository, service, and event contracts.
- `packages/semantic-economy/src/index.ts`: local economy service scaffold for creation, publishing, licensing, purchase/claim/donation/funding, royalties, reviews, search, recommendations, and export.
- Future directories: `assets/`, `marketplace/`, `licensing/`, `ownership/`, `transactions/`, `funding/`, `wallet/`, `royalties/`, `reviews/`, `trust/`, `search/`, `agents/`, `api/`, `events/`, `contracts/`, `schemas/`, `ui/`, `tests/`, and `docs/`.
