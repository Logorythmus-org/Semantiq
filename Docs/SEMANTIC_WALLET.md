# Semantic Wallet

The Semantic Wallet is a semantic ownership system. It is not a cryptocurrency wallet.

## Wallet Contents

- identity
- semantic assets
- ownership claims
- credentials
- certificates
- achievements
- benchmark scores
- learning records
- project contributions
- publications
- licenses
- digital signatures
- future blockchain assets

## Boundaries

The wallet records claims, credentials, provenance, ownership, signatures, and proofs. Payment networks, blockchain networks, and identity providers are optional adapters.

## Local Ownership

Wallet records must work locally and offline. Remote verification can enhance but not replace local ownership records.
