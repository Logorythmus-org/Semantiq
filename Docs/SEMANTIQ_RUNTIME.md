# Semantiq Runtime

The Semantiq Runtime provides explainable evaluation across knowledge objects.

## Dimensions
Reasoning, evidence, scientific quality, educational value, novelty, creativity, collaboration, clarity, consistency, reusability, impact, and reflection.

## Runtime Modules
- Semantic analyzer.
- Reasoning analysis.
- Benchmark runtime.
- Scoring.
- Recommendation.
- Evidence analysis.
- Explanation engine.
- Historical comparison.
- Quality metrics.

The current runtime uses deterministic local heuristics and explicit explanations. Provider-backed evaluators can replace heuristics through future adapters.
