# Simulation Engine

The Simulation Engine tests workflow behavior before execution.

## Simulation Modes
Dry run, debug mode, cost estimate, risk analysis, dependency check, approval-path check, data-flow check, and recovery-path check.

## Outputs
Simulation reports include expected path, blocked nodes, missing permissions, estimated cost, risk notes, approval requirements, benchmark criteria, and graph write projections.

## Offline Mode
Offline simulation uses cached tool metadata, local schema validation, local graph context, and deferred external checks.
