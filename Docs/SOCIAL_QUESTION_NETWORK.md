# Social Question Network

The Social Question Network is the heart of Tech Club. It organizes people around meaningful questions, not posts, likes, followers, or advertising.

## Product Flow

User -> Question -> Exploration -> Evidence -> Collaboration -> Knowledge -> Project -> Innovation.

## Core Systems

- Question Creation
- Question Feed
- Question Profiles
- Question Graph
- Question Discovery
- Question Relations
- Question Lifecycle
- Question Collaboration
- Question Moderation
- Question Reputation
- Question Analytics
- Question Benchmarking

## Ranking Principle

Discovery prioritizes question quality, scientific potential, learning value, collaboration need, evidence quality, semantic novelty, diversity, and curiosity. Popularity never outweighs knowledge quality.

## Platform Integration

Questions use the Data Platform for semantic nodes, Knowledge Graph for relationships, Workspace for collaboration, Identity for permissions and reputation, Semantiq for benchmarking, and Agent OS for assistance.

## Package Layout

- `packages/question-network/src/contracts.ts`: product contracts for questions, profiles, relations, discussion contributions, discovery, feeds, moderation, analytics, repository, and service APIs.
- `packages/question-network/src/index.ts`: local contract scaffold for development and validation.
- Future directories: `question/`, `profiles/`, `discussion/`, `graph/`, `evidence/`, `hypothesis/`, `experiments/`, `benchmark/`, `search/`, `recommendation/`, `moderation/`, `analytics/`, `feeds/`, `schemas/`, `api/`, `ui/`, and `events/`.
