# Synchronization

Workspace synchronization preserves local-first ownership while enabling collaboration.

## Sync Types

Workspace sync, knowledge sync, repository sync, notebook sync, document sync, graph sync, selective sync, background sync, encrypted sync, and future peer-to-peer sync.

## Conflict Handling

Sync plans include object versions, local changes, remote changes, conflicts, resolution strategy, merge records, and audit references.

## Security

Synchronization must support encryption, workspace isolation, permission checks, zero-trust communication, and protected knowledge assets.
