# System Health

System health is a scored view of platform readiness.

## Health Dimensions

Architecture health, dependency health, runtime health, knowledge health, workspace health, workflow health, agent health, marketplace health, API health, performance health, security health, and documentation health.

## Scoring

Each subsystem receives a score from 0 to 100 with explanation, evidence, risks, blockers, and recommended actions.

## Release Gate

MVP release requires no critical blockers in security, architecture, offline, API, documentation, or data integrity dimensions.
