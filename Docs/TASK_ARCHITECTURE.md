# Task Architecture

Tasks are semantic objects connected to questions, evidence, agents, benchmarks, and project goals.

## Task Fields

Priority, dependencies, subtasks, agents, benchmarks, evidence, notes, deadlines, automation, status, review, and linked questions.

## Task Relationships

Tasks can depend on, block, support, verify, implement, review, or benchmark other objects.

## Automation

Tasks can trigger agent runs, scheduled workflows, notifications, benchmark runs, repository operations, or review requests through the kernel and integration layer.
