# Task Scheduler

The Task Scheduler chooses where and how work runs.

## Scheduling Inputs

Priority, resource availability, hardware, latency, power, offline availability, workspace context, agent requirements, knowledge locality, task dependencies, historical performance, permissions, and user policy.

## Explainability

Every scheduling decision stores candidate resources, selected resource, rejected alternatives, reasons, estimated cost, risk, confidence, and benchmark references.

## Strategies

Sequential, parallel, pipeline, map, reduce, scatter, gather, graph execution, recursive execution, adaptive execution, and checkpoint recovery.

## Local-First

The scheduler prefers local and privacy-preserving resources when policy, capability, and performance allow.
