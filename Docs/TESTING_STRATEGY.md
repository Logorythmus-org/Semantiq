# Testing Strategy

## Unit Tests

Validate pure functions and isolated module behavior.

## Integration Tests

Validate package collaboration behind stable contracts.

## Architecture Tests

Validate dependency direction, package exports, and forbidden imports.

## Contract Tests

Validate commands, queries, events, lifecycle, and adapters.

## End-to-End Tests

Validate future user workflows in apps through Playwright.

## Performance Tests

Validate startup, storage, indexing, and compute budgets.

## Future Benchmark Tests

Validate semantic quality and reasoning outcomes through Semantiq-compatible benchmarks.
