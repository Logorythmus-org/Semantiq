# Threat Model

Threats include malicious nodes, impersonation, replay, tampering, compromised invitations, SSRF, resource abuse, malicious remote objects, prompt injection, dependency poisoning, stale/revoked objects, unauthorized replication, policy bypass, exfiltration, graph poisoning, remote agent abuse, denial of service, key compromise, trust escalation, and audit manipulation.

Mitigations are documented in `specs/sprint-5/threat-model.md`.
