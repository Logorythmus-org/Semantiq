# Trust Model

Trust in Tech Club must explain itself.

## Trust Signals

- verified identity
- verified contribution
- verified knowledge
- verified benchmark
- verified research
- verified organization
- confidence
- evidence
- transparency

## Trust Scores

Trust scores are summaries over visible evidence, not opaque judgments. Each score must expose contributing signals, weights, confidence, and uncertainty.

## AI And Trust

Agent output can contribute evidence but cannot silently create trust. Human review and benchmark evidence remain visible.
