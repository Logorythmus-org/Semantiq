# Trust Network

Trust between nodes is explainable and evidence-based.

## Trust Signals
Identity, reputation, research integrity, security, protocol compliance, benchmark quality, availability, transparency, audit history, and regional compliance.

## Trust Records
Trust records store evaluator, subject node, evidence, score, explanation, benchmark references, validity period, and policy scope.

## Transparency
Trust can be challenged, updated, reduced, or scoped. It is never a hidden global score.
