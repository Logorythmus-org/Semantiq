# Vector Storage

Vector storage prepares Tech Club for AI-assisted semantic retrieval.

## Stored Data
- embeddings
- semantic fingerprints
- knowledge clusters
- agent memory vectors
- document similarity vectors
- question similarity vectors
- future multimodal embeddings

## Provider Independence
Vector storage uses provider-neutral contracts. Embeddings record model, dimension, normalization, source object, and permission scope.

## Privacy
Vectors can leak semantic meaning. Reads, writes, exports, and similarity searches must enforce permissions and workspace isolation.
