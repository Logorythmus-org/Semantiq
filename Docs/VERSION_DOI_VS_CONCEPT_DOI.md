# Version DOI vs Concept DOI Strategy

This document clarifies the distinction between **Version DOIs** and **Concept DOIs** for scholarly software citation in **SemantIQ Benchmarks**.

---

## 1. Version DOI (Specific Version)

- **Definition**: Represents a single, specific release of SemantIQ Benchmarks (e.g., `v0.1.0-alpha.1`).
- **Use Case**: Use in research papers when reproducing exact benchmark evaluation scores.
- **Example**: `https://doi.org/10.5281/zenodo.EXAMPLE_VERSION`

---

## 2. Concept DOI (All Versions)

- **Definition**: Represents the overall software project across all versions past, present, and future.
- **Use Case**: Use in generic software citations, acknowledgments, or project references.
- **Example**: `https://doi.org/10.5281/zenodo.EXAMPLE_CONCEPT`

---

## Recommended Citation Guidance

- To cite a specific benchmark run: Cite the **Version DOI**.
- To cite the SemantIQ project in general: Cite the **Concept DOI**.
