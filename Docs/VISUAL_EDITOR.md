# Visual Workflow Editor

The Visual Workflow Editor is a node-based authoring surface for goal execution.

## Capabilities

Drag and drop, zoom, grouping, templates, search, minimap, comments, version comparison, simulation, debug mode, and real-time collaboration.

## Editor Panels

Workflow canvas, node library, property inspector, execution timeline, simulation mode, debug console, template browser, workflow marketplace, agent assignment panel, benchmark viewer, and Knowledge Graph viewer.

## Offline Editing

The editor supports local workflow changes, background validation, cached node metadata, and later synchronization.

## Accessibility

Every visual workflow operation must have keyboard-accessible and structured-data equivalents.
