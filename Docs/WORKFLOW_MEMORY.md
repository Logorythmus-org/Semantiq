# Workflow Memory

Workflow memory stores reusable execution knowledge.

## Stored Records
Inputs, outputs, intermediate results, benchmarks, errors, agent decisions, tool calls, knowledge produced, reflection, and future improvements.

## Reuse
Memory can inform future workflow generation, template selection, simulation, optimization, and risk detection.

## Governance
Memory records include source references, permissions, versions, confidence, and retention policy. Sensitive memory requires encryption and workspace isolation.
