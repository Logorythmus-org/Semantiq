# Workflow Model

Workflows are versioned knowledge assets that describe how a goal becomes executable work.

## Workflow Contents

Each workflow includes identity, name, description, purpose, owner, workspace, project, goal, nodes, edges, conditions, variables, inputs, outputs, agents, tools, permissions, events, execution history, benchmarks, version history, reflection, and knowledge links.

## Lifecycle

Draft -> Generated -> Reviewed -> Approved -> Executed -> Paused -> Resumed -> Completed -> Benchmarked -> Published -> Template -> Archived.

## Versioning

Workflow versions preserve graph structure, generation explanation, risk notes, approval requirements, benchmark references, and reflection links. Published templates reference immutable versions.

## Reuse

Reusable workflows retain their source goal, requirements, assumptions, validation criteria, benchmark results, and known failure modes.
