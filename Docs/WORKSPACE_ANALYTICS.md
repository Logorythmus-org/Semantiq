# Workspace Analytics

Workspace analytics measures the health and productivity of living knowledge spaces.

## Metrics

Workspace health, knowledge growth, research activity, collaboration, execution, agent usage, learning, benchmarks, innovation, performance, and storage.

## Views

Dashboard, timeline, graph analytics, activity feed, benchmark viewer, agent usage, collaboration heatmap, object growth, search health, sync health, and performance profile.

## Governance

Analytics should be explainable, privacy-aware, permissioned, and useful for improving workflows, not for surveillance.
