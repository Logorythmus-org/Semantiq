# Workspace Architecture

The Universal Workspace is Tech Club's primary operating environment. It is not a file explorer and not a conventional project management tool. It is a semantic space where questions, projects, knowledge, documents, agents, workflows, and people collaborate.

## Workspace Layers

- Workspace Shell: application surface, navigation, panels, dashboards, graph views, and mode-specific presentation.
- Workspace Manager: opens, closes, configures, synchronizes, and monitors workspace state.
- Project Manager: manages project lifecycles, goals, milestones, tasks, resources, and outcomes.
- Knowledge Objects: unified objects for questions, answers, observations, documents, notebooks, datasets, tasks, games, and more.
- AI Collaboration Layer: agent assignments, suggestions, reviews, approvals, and human-in-control workflows.
- Execution Layer: code, notebooks, workflows, automations, benchmarks, and scheduled tasks.
- Storage Layer: local-first persistence through the Data Platform.
- Synchronization Layer: offline edits, conflict detection, selective sync, and encrypted sync.
- Presentation Layer: modes, dashboards, panels, graph visualization, and search interfaces.

## Workspace Types

Personal, research, scientific, education, programming, creative, business, organization, community, shared, temporary, offline, and enterprise workspaces inherit common identity, permissions, graph, search, versioning, sync, and automation behavior.

## Rule

Workspace modes configure interface and workflows. They do not change the underlying data model.
