# ADR-0201: Question Aggregate

Status: Deferred

Date: 2026-07-21

## Context

Phase B already owns the authoritative Question aggregate, while Phase E proposes an incompatible title/body and lifecycle model without a valid Phase D handoff.

## Decision

Do not create a second aggregate or replace the Phase B contract in this blocked sprint.

## Consequences

Phase E must later choose an application facade or explicit versioned evolution with migration and compatibility evidence.
