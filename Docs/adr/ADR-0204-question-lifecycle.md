# ADR-0204: Question Lifecycle

Status: Deferred

Date: 2026-07-21

## Context

The accepted lifecycle is published/archived with restore, moderation, revision, and redaction boundaries. Prompt 1 proposes draft, locked, and deleted states.

## Decision

Preserve Phase B lifecycle semantics during this blocked sprint.

## Consequences

New states require versioned domain, API, event, migration, access, and historical-compatibility design.
