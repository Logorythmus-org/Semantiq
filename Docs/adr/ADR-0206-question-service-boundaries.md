# ADR-0206: Question Service Boundaries

Status: Deferred

Date: 2026-07-21

## Context

Phase D has no Runtime Kernel, Workflow, Planning, Agent, or public Semantiq contracts, and posts/comments/answers/tasks have not been accepted as Question-owned concepts.

## Decision

Keep the Phase B Question Runtime boundary unchanged and add no Phase E runtime integration.

## Consequences

Cycle 2 remains blocked; future Discussion and other domains must use public Question contracts rather than shared tables or aggregate aliases.
