# Question Runtime Known Limitations

- Actor headers require a trusted upstream identity boundary.
- Moderator capabilities and rate limits are process-local configuration.
- Search is deterministic substring search, not semantic ranking.
- Frame component IDs are content-addressed read identifiers; removed content remains only in immutable Frame revisions.
- No distributed graph, vector database, AI moderation, truth score, answer generation, appeal workflow, erasure automation, or production retention policy exists.
- Compatibility aliases and non-authoritative conceptual packages remain.
