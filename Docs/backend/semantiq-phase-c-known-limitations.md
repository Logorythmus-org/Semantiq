# Semantiq Phase C Known Limitations

Phase C is not implemented. Missing capabilities include deterministic structural evaluation, persistence, explainability, comparison, benchmarks, evaluator orchestration, persistent jobs, consensus/disagreement views, sources, citations, provenance, reliability, conflicts, replay, security/privacy policy, diagnostics, tests, and Docker evidence.

The legacy Semantiq scaffold is nondeterministic and must not be treated as a fallback runtime.
