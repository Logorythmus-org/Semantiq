## Current documentation audit

Reviewed on 2026-10-06:

- [Provider selection](https://openrouter.ai/docs/guides/routing/provider-selection): `only` and `order` use provider slugs. Base slugs match a provider's endpoint variants; full slugs target a specific variant. `allow_fallbacks: false` prevents backup providers. `require_parameters: true` excludes providers that do not advertise requested parameters. `max_price` constrains eligible pricing.
- [Provider API](https://openrouter.ai/docs/api/api-reference/providers/list-providers): the providers catalogue exposes an explicit `slug`. Current Novita projection is name `Novita`, slug `novita`.
- [Model endpoints](https://openrouter.ai/docs/api/api-reference/endpoints/list-all-endpoints-for-a-model): endpoint metadata separately exposes `provider_name`, `tag`, prices, status and supported parameters. The reviewed reference does not establish that every endpoint `tag` is interchangeable with a provider routing slug.
- [Structured outputs](https://openrouter.ai/docs/guides/features/structured-outputs): `json_schema` and strict schemas depend on model/provider compatibility. An advertised parameter is not proof that a particular schema succeeds. Invalid schemas and incompatible models can fail. Response healing is not enabled.
- [Error contract](https://openrouter.ai/docs/api_reference/errors-and-debugging): retain typed error metadata when available; provider details identify the upstream source. HTTP 200 can also contain a generation error, so success requires checking the parsed body. No debug echo of the upstream request is enabled.
- [Limits](https://openrouter.ai/docs/api_reference/limits): authenticated `free_model_daily_requests` is the request-count projection. Credits, key labels and `is_free_tier` are not request capacity. A counter can settle later; it cannot establish exact POST counts. No credits are purchased.

## Request and routing contract

The diagnostic base-slug policy fails closed unless fresh endpoint discovery contains exactly one endpoint for the selected alias and that endpoint has the expected provider and tag. Before HTTP, canonical local JSON supplies `wireRequestDigest`; credentials and headers are absent. Audit stages distinguish metadata, preparation, POST invocation, headers, bounded body receipt and JSON parsing. POST invocation alone is not server receipt; HTTP response headers provide independent response evidence. Audit timestamps are outside empirical condition identity.

## Error and credential boundary

The credential callback is invoked only at HTTP boundaries. Neither credential nor HTTP headers are retained. Bodies are read with byte limits. Error evidence projects status, allowlisted structural code/type, exact expected upstream provider, validated numeric provider code and recognized upstream parameter/reason enums. It never serializes arbitrary messages, `metadata.raw`, upstream stacks, private paths, cookies or payloads. `sanitizedErrorDigest` hashes this bounded sanitized representation, not the secret-containing raw body. Unparsed bodies retain their status with `ERROR_BODY_UNAVAILABLE_OR_UNPARSED`. Unknown codes, types and reasons remain unknown. Documented request IDs are omitted rather than guessed.

A successful engineering response requires the selected model/provider, cost exactly zero, bounded usage and no embedded generation error. A transport success is separate from a content-contract check. B/C also require exact output JSON; there is no repair, inferred answer or fuzzy parsing. The canonical SemantIQ local response validator is unchanged.

The diagnostic retained three generation requests: A, B and one final B inspection to resolve a missing bounded reason. Every request is preserved; the inspection is not a replacement benchmark observation. Exclusive reservation files prevent rerunning these CLI paths. C is not sent and the ladder is closed. The original A content-check failure and B classification remain historical diagnostic snapshots; separate later analyses explain their limits. All 0.1.1 empirical evidence is byte-verified against its historical head and is never relabeled.
