# Anti-Gaming & Independent Observation

To prevent systems from gaming benchmark evaluations:
- **Independent Observer Mirroring**: Behavioral events are recorded by an isolated observer process that the evaluated agent cannot manipulate.
- **Trajectory Perturbation**: Evaluates system response under randomized noise and simulated intermittent network drops.
- **Merkle Trace Integrity**: Score receipts cannot be modified after execution without invalidating the cryptographic hash chain.
