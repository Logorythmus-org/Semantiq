# Prompt 7 Privacy Register

Public discovery excludes archived and discovery-restricted Questions. Exact, graph, and semantic snapshot reads hide restricted records as not found; moderators with configured capability retain internal access. Reports, audit records, revision history, and internal report counts are not public.

Logs contain bounded identifiers, operation names, counts, codes, durations, and correlation IDs; no Question, Frame, source description, or report text is logged. Retention, erasure, emergency redaction, and appeals remain governance debt, documented as non-blocking for local Phase B.
