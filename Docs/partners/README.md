# Partner Protocols, Pre-Registration & External Evidence Gate

**Status**: `NORMATIVE`  
**Target Audience**: External Academic Labs, Industry Partners, Replication Hubs  

---

## Overview

SemantIQ enables external institutions to submit independent replication studies and empirical observations through cryptographically verifiable, protocol-aware exchange channels.

---

## Documents in this Section

- 📑 **[Preregistered Partner Study Protocols](../RESEARCH_WORKFLOW.md#phase-12-partner-study-preregistration)** (`NORMATIVE`): Freezing protocol parameters, model fingerprints, sample counts, and analysis thresholds before execution.
- 📜 **[Protocol-Aware Study Execution Manifests](../RESEARCH_WORKFLOW.md#phase-13-study-execution-manifests)** (`NORMATIVE`): Immutable execution records with SHA-256 fingerprint verification against frozen registrations.
- 🚪 **[External Evidence Eligibility Gate](../RESEARCH_WORKFLOW.md#phase-14-external-evidence-eligibility-gate)** (`NORMATIVE`): Deterministic 4-status gating (`eligible`, `eligible_with_caveats`, `quarantined`, `rejected`) preventing invalid external submissions from altering evidence aggregation.
- 🔄 **[Cross-Organization Replication Exchange](../RESEARCH_WORKFLOW.md#phase-15-partner-replication-exchange)** (`NORMATIVE`): Context diversity score ($D \ge 0.70$) calculation for Level E4 global consensus.
