# Policy Scope Evaluation Specification

**Project**: SemantIQ Benchmarks  
**Date**: 2026-08-01

---

## Scope Evaluation Dimensions

- **Actor & Role**: Verifies requesting agent against `allowedActors`.
- **Resource & Action**: Verifies requested file or tool path against `allowedResources`.
- **Temporal**: Verifies evaluation timestamp against `validUntil`.
