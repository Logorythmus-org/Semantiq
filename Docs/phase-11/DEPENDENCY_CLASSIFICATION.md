# Dependency Classification Matrix

**Project**: SemantIQ Benchmarks  
**Date**: 2026-08-03  

---

## 8 Classification Categories

1. `SEMANTIQ_OWNED`: Package exports owned by SemantIQ.
2. `EXTERNAL_RUNTIME`: Public external runtime dependencies.
3. `EXTERNAL_DEVELOPMENT`: Development dependencies (`typescript`, `vitest`).
4. `OPTIONAL_ADAPTER`: Optional external integrations.
5. `SHARED_NEUTRAL`: Provider-neutral standards.
6. `PARENT_ONLY`: Non-product parent monorepo packages.
7. `FORBIDDEN`: Restricted domain modules (`@tech-club/wallet`, `@tech-club/marketplace`, etc.).
8. `UNRESOLVED`: Unclassified packages.
