# SemantIQ Non-Goals Specification

**Project**: SemantIQ Benchmarks  
**Date**: 2026-08-01  

---

## SemantIQ Non-Goals

SemantIQ is NOT:
- A social platform or question network (`packages/question-network`).
- A semantic wallet or token economy (`packages/wallet`).
- A civilization OS (`packages/civilization-kernel`).
- A marketplace (`packages/marketplace`).
- A hosted cloud service.
