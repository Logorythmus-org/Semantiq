## Version History & Changes

### `v0.1.0-alpha.1` (Phase 8 API Freeze)
- **Added**: Initial Phase 8 Behavioral Evaluation System.
- **Added**: 9-stage observable lifecycle model.
- **Added**: 44 canonical verbs across 7 verb families.
- **Added**: Environment & permission evaluation, default deny, permission drift detection, secret redaction.
- **Added**: 19 canonical behavioral event types with deterministic serialization, DAG sequence integrity analyzer, SHA-256 evidence verification, and separated evaluator annotation store.
- **Added**: Execution graph builder (9 node types, 12 edge types) and dry replay engine.
- **Added**: Mission contract evaluator, 13 containment failure classes, 9 attribution categories.
- **Added**: Consequence & recovery model (13 lifecycle entities, 12 recovery metrics, incident evidence bundles).
- **Added**: Local synthetic single-agent scenario pack (12 scenarios `SCN_01` to `SCN_12`).
