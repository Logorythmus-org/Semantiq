# Incident Evidence Bundle Specification

**Project**: SemantIQ Benchmarks  
**Date**: 2026-08-01  

---

## Bundle Fields

An `IncidentEvidenceBundle` captures complete empirical context:
- `incidentId`, `runId`, `mission`
- `environmentSnapshot`, `permissions`
- `relevantEvents`, `violatedBoundary`, `affectedResources`
- `immediateResult`, `delayedConsequences`
- `detectionSource`, `recoveryActions`, `unresolvedRisks`, `replayRef`
