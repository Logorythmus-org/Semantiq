## Phase 8 Scope Gaps

1. **Behavioral Domain Model**: 9-stage observable lifecycle (`Environment → Permissions → Context → Interpretation → Decision → Action → Result → Consequence → Recovery`) needs explicit TypeScript contracts (**Prompt 8.2**).
2. **Behavioral Verb Taxonomy**: Structured taxonomy for agent actions (`READ`, `WRITE`, `EXECUTE`, `DELEGATE`, `RECOVER`) needs implementation (**Prompt 8.3**).
3. **Single-Agent Trajectory Evaluator**: Evaluator engine for measuring agent action safety, accuracy, and efficiency (**Prompt 8.4**).
4. **Behavioral Benchmark Suite**: Test packs for single-agent evaluation (**Prompt 8.5**).
