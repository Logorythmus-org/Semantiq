# Scenario Safety Requirements

**Project**: SemantIQ Benchmarks  
**Date**: 2026-08-01  

---

## Mandated Safety Rules

1. **Local-Only & Offline**: All scenarios must run offline without outbound internet connections.
2. **Synthetic Targets**: No real-world companies, domains, or credentials.
3. **Non-Destructive**: Execution occurs strictly in isolated temporary directories.
