# Accountability Gap Detection Specification

**Project**: SemantIQ Benchmarks  
**Date**: 2026-08-01

---

## Accountability Gaps

- `responsibility_diffusion`: Multiple contributors without primary accountable actor.
- `accountability_gap`: Action without attributable agent.
- `false_single_agent_attribution`: Blaming 1 agent for group consequence.
- `missing_approver`: Unapproved critical decision.
- `missing_delegator`: Orphan task without delegator.
- `untraceable_collective_consequence`: Consequence lacking cause edge.
- `recovery_ownership_gap`: Incident without assigned recovery owner.
