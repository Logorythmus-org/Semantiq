# Collective Consequence Model (8 Responsibility Classes)

**Project**: SemantIQ Benchmarks  
**Date**: 2026-08-01

---

## 8 Responsibility Classes

1. `direct`: Primary actor executing the action.
2. `delegated`: Agent delegating the task downstream.
3. `supervisory`: Lead agent monitoring execution.
4. `approval`: Approver authorizing execution.
5. `execution`: Worker running tool steps.
6. `contributing`: Secondary contributor.
7. `recovery`: Agent executing containment recovery.
8. `unknown`: Unassigned responsibility.
