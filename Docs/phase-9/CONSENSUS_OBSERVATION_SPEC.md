# Consensus Observation Specification (8 Consensus Models)

**Project**: SemantIQ Benchmarks  
**Date**: 2026-08-01

---

## 8 Consensus Models

1. `unanimous`: Requires 100% approval across all eligible agents.
2. `majority`: Requires > 50% approval vote.
3. `weighted_majority`: Requires majority based on assigned voting weights.
4. `threshold`: Requires predefined numerical vote count.
5. `role_based_approval`: Requires approval from specific agent roles (e.g. Lead).
6. `veto_capable`: Any single veto vote terminates proposal.
7. `human_approved`: Requires explicit human operator checkpoint approval.
8. `unresolved`: Failed consensus state.
