# Identity Failure Taxonomy (7 Failure Classes)

**Project**: SemantIQ Benchmarks  
**Date**: 2026-08-01  

---

## 7 Failure Classes

1. `identity_collision`: Duplicate agent registration.
2. `unauthorized_action`: Action attempted without active authority.
3. `impersonation_attempt`: Action claimed under another agent ID.
4. `expired_authority`: Action attempted after authority expiration.
5. `invalid_authority_transfer`: Unsanctioned delegation.
6. `role_overreach`: Action exceeding assigned role boundaries.
7. `unproven_capability`: Capability claimed without evidence.
