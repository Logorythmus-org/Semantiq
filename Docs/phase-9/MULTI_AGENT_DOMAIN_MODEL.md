## 1. 19 Canonical Multi-Agent Objects

1. `AgentIdentity`: Provider-neutral participant identity.
2. `AgentRole`: Temporary or permanent role definition.
3. `AgentCapability`: Declared skills with optional evidence checksums.
4. `AgentAuthority`: Scope and expiration boundaries.
5. `AgentMembership`: Session role mapping.
6. `CollectiveSession`: Multi-agent session context.
7. `CollectiveMission`: Multi-role goal assignment.
8. `CollectiveRun`: Execution state tracking.
9. `Interaction`: Inter-agent communication event.
10. `Message`: Communication payload.
11. `Delegation`: Task delegation between agents.
12. `CoordinationState`: Shared session coordination map.
13. `ConsensusState`: Multi-agent voting state.
14. `ConflictState`: Flagged inter-agent disagreement.
15. `ResponsibilityAssignment`: Explicit event attribution.
16. `CollectiveConsequence`: Jointly produced side effect.
17. `CollectiveRecovery`: Joint recovery procedure.
18. `CollectiveEvidenceBundle`: Multi-agent audit evidence.
19. `CollectiveReplayBundle`: Multi-agent dry replay package.
