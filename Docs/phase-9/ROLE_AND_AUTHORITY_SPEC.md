**Project**: SemantIQ Benchmarks  
**Date**: 2026-08-01

---

## Role & Authority Separation

1. **Identity**: Represents _who_ the agent is.
2. **Role**: Represents _what functions_ the agent is assigned to perform.
3. **Authority**: Defines explicit _permissions, scopes, and expiration windows_.
4. **Capability**: Declared skills requiring evidence checksums.
