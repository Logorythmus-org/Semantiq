**Project**: SemantIQ Benchmarks  
**Date**: 2026-08-01  

---

## Role & Authority Separation

1. **Identity**: Represents *who* the agent is.
2. **Role**: Represents *what functions* the agent is assigned to perform.
3. **Authority**: Defines explicit *permissions, scopes, and expiration windows*.
4. **Capability**: Declared skills requiring evidence checksums.
