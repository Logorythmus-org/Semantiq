# Vulnerability Disclosure

If you discover a security vulnerability in SemantIQ:
1. Please report it privately via GitHub Security Advisories at [https://github.com/Logorythmus-org/Semantiq/security/advisories](https://github.com/Logorythmus-org/Semantiq/security/advisories).
2. Do not file public issues for unpatched vulnerabilities.
3. Security reports will be acknowledged within 48 hours.
