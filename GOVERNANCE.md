# Governance

SemantIQ's current repository governance is documented in
[Docs/GOVERNANCE.md](Docs/GOVERNANCE.md).

## Current authority

The repository's canonical CODEOWNER is:

`@Logorythmus-org/semantiq-maintainers`

See [.github/CODEOWNERS](.github/CODEOWNERS).

Changes to protected `main` go through pull-request review, required status
checks, CODEOWNER review, and the active GitHub ruleset. Proposed councils,
domain-owner teams, working groups, or foundation structures are not current
repository authority unless they are explicitly created and reflected in the
canonical governance and CODEOWNERS surfaces.

For contribution paths, see [CONTRIBUTING.md](CONTRIBUTING.md).
