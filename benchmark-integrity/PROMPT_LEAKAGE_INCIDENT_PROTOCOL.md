# Prompt Leakage Incident Protocol

**Version**: 1.0.0  
**Date**: 2026-08-06  

---

## Leakage Incident Steps

1. **Incident Triage**: Detect public disclosure of Tier B/C/D prompts.
2. **Immediate Freeze**: Issue emergency freeze on affected benchmark scoring.
3. **Regeneration**: Replace leaked prompts via transformational generator.
4. **Public Notice**: Post incident entry in public log without revealing secret prompts.
