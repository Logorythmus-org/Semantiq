# Selective Reporting Policy

**Version**: 1.0.0  
**Date**: 2026-08-06

---

## Reporting Rules

1. **Best-Run-Only Prohibited**: Public rankings must report total runs, failed runs, excluded runs, median, best, worst, and variance.
2. **Exclusion Justification**: Excluded runs require documented technical justifications (e.g. timeout, provider API crash).
3. **Auditability**: Raw evidence from all runs must be preserved in evaluation artifacts.
