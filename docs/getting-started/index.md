# Getting Started with SemantIQ

Welcome to **SemantIQ Benchmarks**, an independent, open-source, local-first evaluation toolkit for measuring AI model behavior, reasoning consistency, and execution evidence.

## Quick Start (3-Step Verification)

```bash
# 1. Clone & Install
git clone https://github.com/Logorythmus-org/Semantiq.git
cd Semantiq
pnpm install

# 2. Run First-Run Diagnostics Doctor
pnpm doctor

# 3. Run Local Offline Smoke Test
pnpm smoke
```
