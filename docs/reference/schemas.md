# JSON Schema Reference

SemantIQ defines 37 Draft 2020-12 schemas in `schemas/`:

- `benchmark-report.schema.json`: Benchmark evaluation report format.
- `evidence-receipt.schema.json`: Cryptographic Merkle trace receipt.
- `scenario-pack.schema.json`: Benchmark task and scenario bundle specification.
- `connector-config.schema.json`: Model connector configuration schema.
