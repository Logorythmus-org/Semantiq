## Supporting Multiple Legitimate Rubrics

SemantIQ supports evaluating the same underlying model output across multiple distinct rubrics (e.g. analytical clarity vs. legal clarity).

When rubrics diverge, SemantIQ preserves individual scores rather than forcing them into a single blended score without explicit user authorization.
