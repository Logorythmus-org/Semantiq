# Sprint 2 Requirements

- S2-SEM: Every Semantiq score must include score, level, explanation, observations, weaknesses, suggestions, confidence, and evaluation version.
- S2-QI: Pipeline steps must be independently testable and replaceable.
- S2-APPROVAL: Original questions are never overwritten without explicit user approval.
- S2-SIM: Similarity must never delete questions automatically.
- S2-RES: Question-to-research conversion requires approval.
- S2-EVD: Evidence must preserve provenance and uncertainty.
- S2-HYP: Hypotheses must link to source question, project, evidence, assumptions, and status.
- S2-AI: External providers are disabled unless configured and approved.
- S2-TEST: Critical journey must be automated locally with deterministic providers.
