# Package Format

Standard layout: `manifest.json`, `README.md`, `LICENSE`, `CHANGELOG.md`, `provenance.json`, `compatibility.json`, `capabilities.json`, `permissions.json`, `dependencies.json`, `semantiq/report.json`, `contracts/`, `schemas/`, `assets/`, `examples/`, `tests/`, `docs/`, and `signatures/`.

Integrity: content hash, manifest hash, lockfile, inventory, checksum validation, signature placeholder, tamper detection, and verification report.
