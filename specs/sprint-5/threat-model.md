# Threat Model

Threats: malicious nodes, impersonation, replay, tampering, compromised invitations, SSRF, resource abuse, malicious remote objects, prompt injection, dependency poisoning, stale/revoked objects, unauthorized replication, policy bypass, data exfiltration, graph poisoning, remote agent abuse, denial of service, key compromise, trust escalation, and audit manipulation.

Mitigations: explicit invitations, signed envelopes, nonces, expiration, allowlists, policy checks, approval gates, schema validation, revocation, immutable audit, local-first fallbacks, and manual conflict review.
