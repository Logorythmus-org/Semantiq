# Threat Model Update

Spec ID: S6-THREAT

## Threats

Misconfigured alpha deployments, unsafe plugins, unsafe packages, diagnostic leakage, telemetry misuse, backup theft, restore poisoning, AI provider exposure, prompt injection, malicious invitations, dependency vulnerabilities, fake nodes and accidental over-sharing.

## Mitigations

Safe Mode, consent gates, redaction, signed/integrity backup manifests, invitation-only federation, public limitations and manual review gates.
